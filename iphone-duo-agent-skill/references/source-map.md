## Citation convention

- `[TT-111461]` — claim supported by the named talk.
- `[TT-111461, TT-111466]` — claim synthesized from both talks.
- `Established platform guidance` — ordinary iOS practice, not represented as a Duo-specific source claim.
- `Documentation pending` — the talk names or shows an API, but the iOS 27.1 API reference has not been verified.

Do not use the Tech Talk date as proof of SDK availability or shipping behavior. Do not cite one talk for details stated only in another.
